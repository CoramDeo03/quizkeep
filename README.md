# QUIZKEEP

영어 컴퓨터 네트워크 문제를 맞혀 요새를 지키는 1인용 Tower Defense 게임입니다.

## 실행

Node.js 22 이상과 npm이 필요합니다.

```sh
npm install
npm run dev
```

브라우저에서 터미널에 표시되는 주소(기본 `http://127.0.0.1:5173`)를 엽니다.

```sh
npm test       # 채점 / 전투 / 밸런스 테스트
npm run check  # TypeScript 검사
npm run build  # dist/에 정적 배포 파일 생성
npm run preview
```

별도 서버 API, 계정, GPT 키가 필요하지 않습니다. 글꼴은 로컬 빌드에 포함됩니다. `dist`는 정적 웹 서버에 올릴 수 있으며 HTML 파일을 직접 여는 file:// 실행은 지원하지 않습니다.

## 플레이

1. 시작 화면의 **출제 범위**에서 `전체` / `Chapter 1` / `Chapter 2`를 고릅니다. 챕터 하나만 고르면 그 챕터 문제만 나오고, **전체(모든 챕터)**를 고르면 기존 180문제 문제집을 사용합니다. 선택은 브라우저에 저장됩니다.
2. **전투 시작** → **스테이지 선택**. 스테이지 5개는 앞 스테이지를 깨야 열립니다.

   웨이브는 적이 약 30–80초에 걸쳐 나오도록 길게 구성되어 있습니다(뒤 스테이지일수록 길어짐).

   | # | 스테이지 | 웨이브 | 새 몹 |
   |---|---|---|---|
   | 1 | 초원 길목 | 5 | 슬라임 — 쓰러지면 꼬마 슬라임 2마리로 분열 |
   | 2 | 단풍 숲 | 6 | 박쥐 — 비행, Cannon 포탄·폭발에 맞지 않음 |
   | 3 | 얼어붙은 협곡 | 7 | 주술사 — 4초마다 주변 적 체력 10% 회복 |
   | 4 | 불타는 화산 | 8 | **빙결 기술자** — 20초마다 근처 최고 레벨 타워를 얼림(공격 정지, 기술자가 여러 마리여도 12초에 한 번만). 평균보다 레벨이 높을수록 오래(3–8초). 그 타워 문제를 맞히면 해동(그 정답은 레벨업 대신 해동에 쓰임) |
   | 5 | 공허의 왕좌 | 5 | 공허 임프 — 3.5초마다 앞으로 순간이동 · **보스전**(공허의 왕이 6초마다 부하 소환) |

   뒤 스테이지에는 앞에서 나온 몹도 섞여 나옵니다. 준비 화면에 다음 웨이브 몹의 능력과 NEW 표시가 나옵니다.

3. 맵의 **빈 터(+ 팻말)** 클릭 → 원형 메뉴에서 타워 선택. 타워는 사거리 안의 적을 **자동으로 공격**합니다.
4. 웨이브 중 **업그레이드할 타워를 하나 선택**(맵 클릭, 하단 목록, 숫자키 1–8)하고 그 타워의 문제를 풉니다. Archer=O/X, Cannon=객관식, Sniper=단답형(계산), Laser=서술형.
5. 정답이면 **선택한 그 타워만** 레벨 업: Archer +1, Cannon +2, Sniper +3, Laser +4. 연속 정답 콤보 보너스는 3콤보부터 +1, 6콤보부터 +2. 오답이면 그 타워 −1레벨, 콤보 초기화, 3초 동안 답할 수 없습니다.
   - **Laser**(서술형): 체력이 가장 많은 적(보스 우선)에게 빔을 계속 쏩니다. 같은 적을 4초 조준하면 피해가 ×4까지 오르고, 진화할 때마다 최대 배율 +1(전설 ×7). 대상이 죽거나 사거리를 벗어나면 다시 ×1부터 시작하고, 방어력을 무시합니다. 잡몹 떼보다 보스·탱커에 강합니다.
6. **10레벨마다 진화**: 기본(1–10) → 강화(11–20) → 정예(21–30) → 전설(31–40). **최대 Lv40.** 모습이 바뀌고 사거리가 늘며, Archer는 2·3연발, Cannon은 전설 등급에서 쌍포, Laser는 최대 증폭이 커집니다.
   - **한 타워 몰빵 방지:** 등급이 오를수록 정답 한 번의 상승폭이 줄어요(÷1·÷2·÷3·÷4, 최소 +1). 한 타워는 **다른 타워 평균 레벨 +15**까지만 오릅니다(균형 제한). MAX나 균형 제한에 걸린 타워의 정답은 +6 골드가 됩니다. 대포 범위 피해는 주변 적에게 50%만 들어가요.
7. **시간 감속(F)**: 웨이브당 2회, 8초 동안 35% 속도. 준비 단계에서는 타워를 눌러 건설비 70%에 판매할 수 있습니다.
8. **복습 시간**: 웨이브가 끝나면 그 웨이브에서 틀린 문제를 다시 풉니다. 맞히면 문제당 +12 골드, 또 틀리거나 건너뛴 문제는 다음 웨이브 뒤 복습에 다시 나옵니다. 복습을 끝내거나 건너뛰어야 다음 웨이브를 시작할 수 있습니다(마지막 웨이브에서 틀린 문제는 결과 화면에서 복습).
9. 모든 웨이브를 막으면 **스테이지 클리어**(남은 체력에 따라 별 1–3개) → 다음 스테이지. 보스가 성에 닿으면 즉시 패배합니다. 결과 화면에서 틀린 문제와 해설을 복습할 수 있습니다. 진행도와 별은 브라우저에 저장됩니다.

단축키: **1–8** 타워 선택, **O / X** 참·거짓, **A–D** 객관식, **Enter** 단답 제출, **Ctrl/⌘+Enter** 서술형 제출, **F** 시간 감속, **Space** 일시정지, **Esc** 선택 해제.

## 챕터별 문제집

`public/data/manifest.json`이 어떤 파일을 쓸지 정합니다.

```json
{"full":"questions.en.json","chapters":"computer_networks_midterm_quiz_by_chapter.json"}
```

- `full`: **전체**를 골랐을 때 쓰는 문제집(아래 기본 문제집).
- `chapters`: `chapter_1`, `chapter_2`, … 키로 나뉜 챕터별 원본. 키 개수만큼 챕터 버튼이 자동으로 생깁니다. GPT로 같은 형식의 파일을 만들어 교체하면 됩니다.
- 챕터 원본의 단답형 `keywords`, 서술형 `required_keywords`는 **부분 점수식 핵심어**로 바뀝니다. 문제 문장에 이미 나온 핵심어는 빼고, 남은 핵심어 중 단답형은 절반 이상, 서술형은 60% 이상 포함하면 정답입니다. 정확한 모범답안과 일치해도 정답입니다(앞의 a/an/the 무시). 복수형·queueing/queuing 같은 간단한 변형은 자동 허용합니다.
- 이 방식은 기존 180문제의 수작업 채점 기준보다 **관대**합니다. 핵심어만 나열해도 맞을 수 있으니 해설을 함께 확인하세요.

## 계산형 단답 문제

`manifest.json`의 `shortAnswers`(`computer_networks_short_answer_calculation_addon.json`)가 있으면:

- 그 파일의 계산 문제 40개(챕터당 20개)가 **단답형(Sniper)** 문제가 됩니다. 챕터를 고르면 그 챕터의 계산 문제만 나옵니다.
- 원래 단답형이던 문장형 문제(기존 50개, 챕터별 20개씩)는 **서술형(Laser)** 으로 옮겨지고, 기존 핵심어 채점 기준을 그대로 씁니다.
- 결과: 전체 220문제(O/X 50 · 객관식 50 · 단답 40 · 서술 80), 챕터별 150문제(50 · 40 · 20 · 40).
- 계산 답은 숫자와 단위로 채점합니다. `4 ms`, `4ms`, `0.004 s`, 단위 생략 `4`, 풀이를 쓴 `12000/3000000 = 0.004 s`(마지막 값 사용)가 모두 정답이고, `4 s`처럼 단위 환산 값이 다르면 오답입니다. 시간(s·ms·min·h), 전송률(bps·Kbps·Mbps·Gbps), 비트 단위를 환산하고, `About …` 답은 ±2% 오차를 허용합니다. `1 hour 2 minutes` 같은 복합 단위는 지원하지 않습니다.

## 현재 기본 문제집

사용자가 제공한 `computer_networks_midterm_quiz.json`의 180문제를 사용합니다.

- True / False 50, Multiple Choice 50, Short Answer 50, Open-ended 30
- 범위: Chapter 1(인터넷 역사 제외), Chapter 2 Part 1, Chapter 2 Part 2의 DNS까지(17페이지)
- 원문 보존본: `public/data/computer_networks_midterm_quiz.original.json`
- 실행용 정규화본: `public/data/questions.en.json`
- 변환 및 문항별 채점 기준: `scripts/import-midterm.py`

원본 문항, 선택지, 모범답안은 보존했습니다. 단답형에도 문장·공식·목록 문항이 있어, 단순 문자열 일치 외에 문항별 핵심어 그룹을 지원합니다. 대소문자, 공백, 명시된 동의어·복수형·약어를 허용합니다. 계층처럼 순서를 요구하는 일부 목록은 순서도 검사합니다.

**핵심어 채점은 문장 의미, 부정, 인과관계를 이해하지 않습니다.** 필요한 핵심어를 포함해도 논리가 틀리면 시험의 정답이 아닐 수 있으므로 모범답안도 함께 확인하세요. 제공받지 않은 강의 PDF의 내용까지 독립적으로 검증했다고 가정하지 않습니다.

시작 화면의 **JSON 가져오기**로 문제집을 바꿀 수 있습니다. 이 변경은 현재 탭의 메모리에만 적용되고 새로고침하면 기본 문제집으로 돌아갑니다. 원본 그룹형 파일도 가져올 수 있습니다. 배포 기본값은 실행용 JSON을 교체하면 됩니다.

자세한 데이터 규격과 GPT 프롬프트는 [문제집 가이드](docs/question-packs.md)를 참고하세요.

## 구조

- `src/game`: 스테이지 정의(`stages.ts`), 설정(`config.ts`), 고정 시간 간격 전투 엔진(`engine.ts`), 카툰 스타일 Canvas 렌더러(`renderer.ts` — 맵·타워·적·투사체·이펙트를 모두 코드로 그림, 이미지 에셋 없음).
- `src/quiz`: 타입, 검증·가져오기, 섞기, 채점, 챕터별 원본 변환(`chapters.ts`). 게임 수치가 없습니다.
- `src/ui`, `src/App.tsx`: HUD·원형 건설 메뉴·스킬 버튼·퀴즈 두루마리 UI, 캔버스 초상화(`Sprite`), 효과음, 결과 복습.
- `tokens.css`: UI 색상·폰트 토큰(Lilita One, Jua). 전장 색은 `renderer.ts`의 `C` 팔레트.
- `tests`: 문제 원문 보존, 모범답안 통과, 강화, 전투, 재시작, 전체 캠페인 시뮬레이션.

밸런스는 `src/game/config.ts`(타워·적·진화 수치)와 `src/game/stages.ts`(스테이지별 맵, 웨이브, 체력 배율, 보스 체력)에서 수정합니다. `tests/balance.test.ts`가 "항상 가장 약한 타워를 올리는" 가상 플레이어로 각 스테이지를 끝까지 돌려 확인합니다: 문제를 안 풀면 모든 스테이지에서 패배하고, 클리어에 필요한 정답률은 스테이지 1부터 60% → 65% → 70% → 75% → 80%로 올라갑니다. 풀이 시간은 T/F 4초, 객관식 7초, 단답형 12초, 서술형 20초로 가정하므로 실제 체감 난도는 다를 수 있습니다.

최고 기록과 음소거 설정만 localStorage에 저장합니다. 진행 중인 전투 및 작성 답안은 새로고침 시 초기화됩니다. 외부 분석·추적 서비스는 없습니다.
