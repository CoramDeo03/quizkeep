# QUIZKEEP

영어 컴퓨터 네트워크 문제를 맞혀 요새를 지키는 1인용 Tower Defense 게임입니다.

## 실행

Node.js 22 이상과 npm이 필요합니다.

```sh
npm install
npm run dev
```

브라우저에서 터미널에 표시되는 주소(기본 `http://127.0.0.1:5173`)를 엽니다.

```sh
npm test       # 채점 / 전투 / 밸런스 테스트
npm run check  # TypeScript 검사
npm run build  # dist/에 정적 배포 파일 생성
npm run preview
```

별도 서버 API, 계정, GPT 키가 필요하지 않습니다. 글꼴은 로컬 빌드에 포함됩니다. `dist`는 정적 웹 서버에 올릴 수 있으며 HTML 파일을 직접 여는 file:// 실행은 지원하지 않습니다.

## 플레이

1. 시작 화면의 **출제 범위**에서 `전체` / `Chapter 1` / `Chapter 2`를 고릅니다. 챕터 하나만 고르면 그 챕터 문제만 나오고, **전체(모든 챕터)**를 고르면 기존 180문제 문제집을 사용합니다. 선택은 브라우저에 저장됩니다.
2. **전투 시작** → **스테이지 선택**. 스테이지 5개는 앞 스테이지를 깨야 열립니다.

   웨이브는 적이 약 30–80초에 걸쳐 나오도록 길게 구성되어 있습니다(뒤 스테이지일수록 길어짐).

   | # | 스테이지 | 웨이브 | 새 몹 |
   |---|---|---|---|
   | 1 | 초원 길목 | 5 | 슬라임 — 쓰러지면 꼬마 슬라임 2마리로 분열 · **도둑** — 아주 빠르고, 성에 닿으면 체력 대신 골드 30을 훔침 |
   | 2 | 단풍 숲 | 6 | 박쥐 — 비행, Cannon 포탄·폭발에 맞지 않음 · **방패병** — Archer·Cannon 피해(독·화염 포함) 75% 감소, Sniper·Laser로 상대 |
   | 3 | 얼어붙은 협곡 | 7 | 주술사 — 4초마다 주변 적 체력 10% 회복 · **폭탄병** — 쓰러지면 폭발해 반경 120 안의 타워가 3초 동안 공격 못 함 |
   | 4 | 불타는 화산 | 8 | **입구 두 곳**(위·아래 길이 가운데서 합류) · **빙결 기술자** — 20초마다 근처 최고 레벨 타워를 얼림(공격 정지, 기술자가 여러 마리여도 12초에 한 번만). 평균보다 레벨이 높을수록 오래(3–8초). 그 타워 문제를 맞히면 해동(그 정답은 레벨업 대신 해동에 쓰임) |
   | 5 | 공허의 왕좌 | 5 | **갈라지는 길**(가운데 섬을 두고 위·아래로 갈라졌다 다시 합류) · 공허 임프 — 3.5초마다 앞으로 순간이동 · **보스전**(공허의 왕이 6초마다 부하 소환, 항상 위쪽 길) |

   길이 두 갈래인 스테이지에서는 적이 번갈아 두 길로 나옵니다.

   뒤 스테이지에는 앞에서 나온 몹도 섞여 나옵니다. 준비 화면에 다음 웨이브 몹의 능력과 NEW 표시가 나옵니다.

3. 맵의 **빈 터(+ 팻말)** 클릭 → 원형 메뉴에서 타워 선택. 타워는 사거리 안의 적을 **자동으로 공격**합니다.
4. 웨이브 중 **업그레이드할 타워를 하나 선택**(맵 클릭, 하단 목록, 숫자키 1–8)하고 그 타워의 문제를 풉니다. Archer=O/X, Cannon=객관식, Sniper=단답형(계산), Laser=서술형.
5. 정답이면 **선택한 그 타워만** 레벨 업: Archer +1, Cannon +2, Sniper +4, Laser +6. 어려운(오래 걸리는) 유형일수록 한 번에 많이 올라서, **1분 동안 푼 문제로 오르는 레벨은 유형마다 비슷**합니다. 연속 정답 콤보는 3콤보부터 레벨업 ×1.5, 6콤보부터 ×2. 오답이면 그 타워 레벨이 내려가고(O/X −1, 객관식 −1, 단답·서술 −2, 등급이 높을수록 덜), 콤보 초기화, 3초 동안 답할 수 없습니다. O/X는 오답 손해가 정답 이득과 같아서 찍기로는 오르지 않습니다.
   - **Laser**(서술형): 체력이 가장 많은 적(보스 우선)에게 빔을 계속 쏩니다. 같은 적을 4초 조준하면 피해가 ×4까지 오르고, 진화할 때마다 최대 배율 +1(전설 ×7). 대상이 죽거나 사거리를 벗어나면 다시 ×1부터 시작하고, 방어력을 무시합니다. 잡몹 떼보다 보스·탱커에 강합니다.
6. **10레벨마다 진화**: 기본(1–10) → 강화(11–20) → 정예(21–30) → 전설(31–40). **최대 Lv40.** 모습이 바뀌고 사거리가 늘며, Archer는 2·3연발, Cannon은 전설 등급에서 쌍포, Laser는 최대 증폭이 커집니다.
   - **진화 갈래:** 진화할 때마다(Lv11·21·31) 그 타워의 두 갈래 중 하나를 고릅니다. 같은 갈래를 다시 고르면 II·III으로 강해지고, 섞어서 고를 수도 있어요. 고를 갈래가 있으면 타워 위와 하단 버튼에 **!** 가 뜹니다. 레벨이 진화 아래로 떨어지면 마지막 갈래는 다시 진화할 때까지 꺼집니다.

     | 타워 | 갈래 A | 갈래 B |
     |---|---|---|
     | Archer | **독화살** — 맞은 적이 3초 동안 화살 피해의 50/80/110%를 매초 입음(방어력 무시) | **관통 화살** — 주변 적 1/2/3명을 더 맞힘(60% 피해) |
     | Cannon | **넉백 포탄** — 폭발에 맞은 적을 10/16/22 뒤로 밀어냄(보스 제외, 철갑 오크는 절반) | **화염 장판** — 떨어진 자리가 3초 동안 불탐(매초 포탄 피해의 25/40/55%, 비행 제외) |
     | Sniper | **헤드샷** — 20/35/50% 확률로 ×2.5 치명타 | **처형** — 맞은 뒤 체력 12/18/25% 이하인 적은 즉사(보스 제외) |
     | Laser | **분광 빔** — 빔이 주변 적 1/2/3명에게 갈라짐(35% 피해) | **과충전** — 충전 시간 3.2/2.4/1.6초, 최대 배율 +1/+2/+3 |
   - **조준 우선순위:** 타워를 선택하면 **선두**(성에 가장 가까운 적) · **강한 적**(체력 많은) · **약한 적** · **비행** 중 먼저 쏠 대상을 고릅니다. 기본값은 Archer·Cannon 선두, Sniper·Laser 강한 적. Cannon은 비행을 맞힐 수 없어 비행 옵션이 없습니다.
   - **한 타워 몰빵 방지:** 등급이 오를수록 정답 한 번의 상승폭이 줄어요(÷1·÷2·÷3·÷4, 최소 +1). 한 타워는 **다른 타워 평균 레벨 +15**까지만 오릅니다(균형 제한). MAX나 균형 제한에 걸린 타워의 정답은 +6 골드가 됩니다. 대포 범위 피해는 주변 적에게 50%만 들어가요.
7. **×2 배속(S)**: 전투를 두 배 속도로 진행합니다. 오답 패널티·시간 감속 같은 시간은 실제 초로 흐르고, 시간 감속이나 계산·서술형 감속이 켜져 있으면 그쪽이 우선합니다.
   **다음 웨이브 조기 호출(N)**: 웨이브의 적이 모두 나온 뒤에는 입구에 **NEXT** 버튼이 뜹니다. 누르면 남은 적이 있는 채로 다음 웨이브가 시작되고, 지금 웨이브의 클리어 골드를 바로 받으며 보너스(10 + 남은 적 × 3, 최대 60)를 더 받습니다. 그 사이의 복습 시간은 건너뛰고, 틀린 문제는 다음 복습에 함께 나옵니다. 마지막 웨이브에서는 쓸 수 없습니다.
   **시간 감속(F)**: 웨이브당 2회, 8초 동안 35% 속도. 준비 단계에서는 타워를 눌러 건설비 70%에 판매할 수 있습니다.
8. **복습 시간**: 웨이브가 끝나면 그 웨이브에서 틀린 문제를 다시 풉니다. 맞히면 문제당 +12 골드, 또 틀리거나 건너뛴 문제는 다음 웨이브 뒤 복습에 다시 나옵니다. 복습을 끝내거나 건너뛰어야 다음 웨이브를 시작할 수 있습니다(마지막 웨이브에서 틀린 문제는 결과 화면에서 복습).
9. **서술형 자기 채점**: 핵심어 채점은 관대해서, 서술형은 맞혀도 자동으로 다음 문제로 넘어가지 않고 모범답안을 보여줍니다. 내 답이 부족했다면 **사실 부족했어요**를 누르세요. 타워 레벨은 그대로이고, 그 문제는 오답으로 기록되어 다음 복습과 오답 노트에 다시 나옵니다. 복습 시간의 서술형도 같습니다.
10. **계산·서술형 푸는 중 감속**: Sniper(계산)나 Laser(서술형) 문제의 답 칸에 커서가 있는 동안 전투가 50% 속도로 흐릅니다. 계산은 손으로 풀고 서술형은 영어로 써야 해서 오래 걸리기 때문입니다(시간 감속 F가 켜져 있으면 그쪽이 우선). 게임 방법(?) 창에서 끌 수 있습니다.
11. 모든 웨이브를 막으면 **스테이지 클리어**(남은 체력에 따라 별 1–3개) → 다음 스테이지. 보스가 성에 닿으면 즉시 패배합니다. 결과 화면에서 틀린 문제와 해설을 복습할 수 있습니다. 진행도와 별은 브라우저에 저장됩니다.

## 학습 기록 · 오답 노트

푼 문제마다 맞힘/틀림이 브라우저에 저장되고(판이 끝나도, 새로고침해도 유지), 다음 판의 출제에 반영됩니다.

- **출제 가중치**: 문제마다 Leitner 상자(0–4)가 있습니다. 맞히면 한 칸 올라가고 틀리면 0으로 떨어집니다. 한 바퀴를 돌 때 **틀린 문제가 항상 먼저**, 그다음 헷갈리는 문제·새 문제 순으로 나오고, 잘 아는 문제(상자 2·3·4)는 각각 70%·45%·25% 확률로만 나옵니다.
- **오답 노트**: 틀린 뒤 아직 **두 번 연속** 맞히지 못한 문제들. 시작 화면 출제 범위의 **오답 노트** 칩을 누르면 그 문제들로만 플레이합니다(전체·챕터 문제집을 통틀어 모음). 오답이 없는 문제 유형은 전체 문제집에서 나옵니다.
- **학습 기록** 버튼: 선택한 범위의 풀어 본 문제 수, 누적 정답률, **주제별·유형별 정답률(약한 순)**을 보여줍니다. 여기서 오답 노트를 바로 시작하거나 기록을 초기화할 수 있습니다.
- 결과 화면에는 **이번 판 주제별 정답률**이 나옵니다.

**문제 글자 크기**: 문제 패널 맨 위의 **− / +** 버튼(또는 `-` / `=` 키)으로 90%–200%까지 조절합니다. 가운데 숫자를 누르면 100%로 돌아갑니다. 문제·보기·답 입력칸·해설·복습과 결과 화면의 틀린 문제 목록이 함께 커지고, 글자가 커질수록 패널도 조금 넓어집니다. 설정은 브라우저에 저장되고 게임 방법(?) 창에서도 바꿀 수 있습니다.

단축키: **1–8** 타워 선택, **O / X** 참·거짓, **A–D** 객관식, **Enter** 단답 제출, **Ctrl/⌘+Enter** 서술형 제출, **F** 시간 감속, **S** 배속, **- / =** 문제 글자 크기, **N** 다음 웨이브 조기 호출, **Space** 일시정지, **Esc** 선택 해제.

## 챕터별 문제집

`public/data/manifest.json`이 어떤 파일을 쓸지 정합니다.

```json
{"full":"questions.en.json","chapters":"computer_networks_midterm_quiz_by_chapter.json"}
```

- `full`: **전체**를 골랐을 때 쓰는 문제집(아래 기본 문제집).
- `chapters`: `chapter_1`, `chapter_2`, … 키로 나뉜 챕터별 원본. 키 개수만큼 챕터 버튼이 자동으로 생깁니다. GPT로 같은 형식의 파일을 만들어 교체하면 됩니다.
- 챕터 원본의 단답형 `keywords`, 서술형 `required_keywords`는 **부분 점수식 핵심어**로 바뀝니다. 문제 문장에 이미 나온 핵심어는 빼고, 남은 핵심어 중 단답형은 절반 이상, 서술형은 60% 이상 포함하면 정답입니다. 정확한 모범답안과 일치해도 정답입니다(앞의 a/an/the 무시). 복수형·queueing/queuing 같은 간단한 변형은 자동 허용합니다.
- `extras`: 챕터 하나짜리 별도 파일 목록(`{"id","title","file"}`). 지금은 **Chapter 2-1**(`chapter_2_part1_quiz_160.json`, Chapter 2 Part 1 강의 PDF만으로 만든 160문제: O/X 50 · 객관식 50 · 계산 30 · 서술 30)이 있습니다. 파일 안의 `calculation`은 계산형 단답(Sniper)이 됩니다. 시작 화면에 칩이 따로 생깁니다. **Chapter 2-1**만 누르면 그 160문제만 나오고, 이어서 Chapter 1을 누르면 둘을 합치며, Chapter 1·2를 모두 더하면 기존 전체 문제집 + 160문제가 됩니다. **전체** 칩은 기존 문제집 그대로입니다.
- 서술형에 `concepts`(동의어 묶음 배열)와 `min_concepts`를 직접 적으면 자동 핵심어 대신 그 채점 기준을 씁니다. 핵심어가 모두 문제 문장에 들어 있어 자동 기준이 약해지는 문제(Chapter 2-1의 OE06·13·19·22·28·29)에 넣어 두었습니다.
- 이 방식은 기존 180문제의 수작업 채점 기준보다 **관대**합니다. 핵심어만 나열해도 맞을 수 있으니 해설을 함께 확인하세요.

## 계산형 단답 문제

`manifest.json`의 `shortAnswers`(`computer_networks_short_answer_calculation_addon.json`)가 있으면:

- 그 파일의 계산 문제 40개(챕터당 20개)가 **단답형(Sniper)** 문제가 됩니다. 챕터를 고르면 그 챕터의 계산 문제만 나옵니다.
- 원래 단답형이던 문장형 문제(기존 50개, 챕터별 20개씩)는 **서술형(Laser)** 으로 옮겨지고, 기존 핵심어 채점 기준을 그대로 씁니다.
- 결과: 전체 220문제(O/X 50 · 객관식 50 · 단답 40 · 서술 80), 챕터별 150문제(50 · 40 · 20 · 40).
- 계산 답은 숫자와 단위로 채점합니다. `4 ms`, `4ms`, `0.004 s`, 단위 생략 `4`, 풀이를 쓴 `12000/3000000 = 0.004 s`(마지막 값 사용)가 모두 정답이고, `4 s`처럼 단위 환산 값이 다르면 오답입니다. 시간(s·ms·min·h), 전송률(bps·Kbps·Mbps·Gbps), 비트 단위를 환산하고, `About …` 답은 ±2% 오차를 허용합니다. `1 hour 2 minutes` 같은 복합 단위는 지원하지 않습니다.

- 변환 및 문항별 채점 기준: `scripts/import-midterm.py`

원본 문항, 선택지, 모범답안은 보존했습니다. 단답형에도 문장·공식·목록 문항이 있어, 단순 문자열 일치 외에 문항별 핵심어 그룹을 지원합니다. 대소문자, 공백, 명시된 동의어·복수형·약어를 허용합니다. 계층처럼 순서를 요구하는 일부 목록은 순서도 검사합니다.

**핵심어 채점은 문장 의미, 부정, 인과관계를 이해하지 않습니다.** 필요한 핵심어를 포함해도 논리가 틀리면 시험의 정답이 아닐 수 있으므로 모범답안도 함께 확인하세요. 제공받지 않은 강의 PDF의 내용까지 독립적으로 검증했다고 가정하지 않습니다.

시작 화면의 **JSON 가져오기**로 문제집을 바꿀 수 있습니다. 이 변경은 현재 탭의 메모리에만 적용되고 새로고침하면 기본 문제집으로 돌아갑니다. 원본 그룹형 파일도 가져올 수 있습니다. 배포 기본값은 실행용 JSON을 교체하면 됩니다.

자세한 데이터 규격과 GPT 프롬프트는 [문제집 가이드](docs/question-packs.md)를 참고하세요.

## 구조

- `src/game`: 스테이지 정의(`stages.ts`, 길은 `routes` 배열 — 2개면 두 갈래), 설정(`config.ts` — 타워·적·진화 갈래 `PERK` 수치), 고정 시간 간격 전투 엔진(`engine.ts`), 카툰 스타일 Canvas 렌더러(`renderer.ts` — 맵·타워·적·투사체·이펙트를 모두 코드로 그림, 이미지 에셋 없음).
- `src/quiz`: 타입, 검증·가져오기, 섞기, 채점, 챕터별 원본 변환(`chapters.ts`), 학습 기록·오답 노트·약점 통계(`study.ts`). 게임 수치가 없습니다.
- `src/ui`, `src/App.tsx`: HUD·원형 건설 메뉴·스킬 버튼·퀴즈 두루마리 UI, 캔버스 초상화(`Sprite`), 효과음, 결과 복습.
- `tokens.css`: UI 색상·폰트 토큰(Lilita One, Jua). 전장 색은 `renderer.ts`의 `C` 팔레트.
- `tests`: 문제 원문 보존, 모범답안 통과, 강화, 전투, 재시작, 전체 캠페인 시뮬레이션.

밸런스는 `src/game/config.ts`(타워·적·진화 수치, 정답 레벨·오답 손해)와 `src/game/stages.ts`(스테이지별 맵, 웨이브, 체력 배율, 보스 체력)에서 수정합니다.

### 밸런스 검증

`tests/sim.ts`는 실시간으로 문제를 푸는 가상 플레이어입니다. **정답률**, **풀이 속도**(유형별 풀이 시간 O/X 6초 · 객관식 10초 · 단답 25초 · 서술 40초에 곱하는 배수 — 같은 시간에 푸는 문제 수가 달라짐), **전략**을 바꿔 가며 여러 무작위 시드로 돌려 승률을 봅니다. 정답 뒤 다음 문제까지의 대기, 오답 뒤 해설 읽기, 계산·서술형 푸는 중 감속, 웨이브 사이 복습(골드)까지 실제 화면 흐름대로 흉내 냅니다.

- 전략: 가장 약한 타워 올리기(기본) · 진화 갈래·조기 호출·시간 감속까지 쓰는 플레이어(갈래 A/B 각각) · O/X·객관식만 푸는 플레이어 · 한 타워 몰빵 · O/X 찍기 · ×2 배속 · 계산·서술형 감속 끄기
- `npx vite-node scripts/balance-report.ts -- all 12` — 스테이지별 승률표(정답률 × 풀이 속도)와 전략별 승률
- `npx vite-node scripts/balance-sweep.ts -- 3 10 .7 .75 .8` — 적 체력 배율 후보별 승률(파일은 바꾸지 않음)

`tests/balance/stage1–5.test.ts`가 지키는 목표(시드 8개 기준):

| | 스테이지 1 | 2 | 3 | 4 | 5 |
|---|---|---|---|---|---|
| 보통 속도로 70% 이상 승리하는 정답률 | 50% | 60% | 70% | 80% | 80% |
| 이 정답률이면 대부분 패배(승률 ≤35%) | 30% | 40% | 50% | 60% | 50% |

- **정답률이 중요:** 위 표.
- **푼 양이 중요:** 같은 정답률(기준 −10%p)에서 빠른 플레이어(0.6배 시간)가 느린 플레이어(1.5배 시간)보다 승률이 40%p 이상 높습니다.
- 가상 플레이어는 모든 유형을 같은 정답률로 풉니다. 실제로는 계산 문제 정답률이 낮은 경우가 많아서, 체감 난도는 표보다 높을 수 있습니다.
- 문제를 안 풀거나 O/X를 찍어서는 어느 스테이지도 못 깹니다. 3스테이지부터 한 타워 몰빵은 집니다. 4·5스테이지는 O/X·객관식만 풀면 모든 유형을 푼 플레이어보다 승률이 20%p 이상 낮습니다. 진화 갈래 A·B 모두 쓸 만합니다.

16시드 측정 예(보통 속도 승률): 스테이지 4 — 정답률 60% 6% · 70% 63% · 80% 88% · 90% 100%. 같은 70%라도 빠르면 94%, 느리면 19%. 가상 플레이어는 실제 사람보다 단순하므로 체감 난도는 다를 수 있습니다.

스테이지 진행도·별, 출제 범위, 음소거·입력 감속·문제 글자 크기 설정, 문제별 학습 기록(`quizkeep-study`)을 localStorage에 저장합니다. 학습 기록은 문제 id와 문제 문장으로 구분하므로 다른 문제집을 가져와도 섞이지 않습니다. 진행 중인 전투 및 작성 답안은 새로고침 시 초기화됩니다. 외부 분석·추적 서비스는 없습니다.
